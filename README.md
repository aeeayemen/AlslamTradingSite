## 📌 نبذة عن المشروع | Overview

الموقع الرسمي ومنظومة إدارة المحتوى المتكاملة لـ **مؤسسة السلام للتجارة والتوكيلات العامة**. يوفر النظام واجهة أمامية تفاعلية ثنائية اللغة (العربية والإنجليزية) تستعرض أنشطة وقطاعات وخدمات ومنتجات وشركاء المؤسسة، مدعومة بنظام إدارة محتوى متطور (**TechCMS**) يتيح التحكم الكامل في كافة البيانات والصفحات والوسائط والمستخدمين والصلاحيات.

تم تحديث النظام وترقيته بالكامل ليتوافق مع أحدث إصدارات **PHP 8+** ومعايير الأمان الحديثة مع ربطه بقاعدة بيانات سحابية متقدمة (MySQL 8.0).

## 🚀 المميزات الرئيسية | Key Features

### 🌐 1. الواجهة الأمامية (Frontend)
- **تصميم متجاوب ومتوافق (Fully Responsive):** يدعم الهواتف الذكية والأجهزة اللوحية وأجهزة الكمبيوتر بسلاسة.
- **دعم متعدد اللغات (Multilingual):** دعم كامل للغتين العربية والإنجليزية مع دعم اتجاهات القراءة (RTL / LTR).
- **أقسام الشركات والقطاعات:** استعراض تفاعلي لقطاعات المؤسسة، الأنشطة، والشركات التابعة.
- **المنتجات والخدمات والمشاريع:** كاتالوج متكامل للمنتجات وتفاصيلها مع معارض الصور.
- **إحصائيات وحقائق تفاعلية (Counters & Facts):** عرض إنجازات المؤسسة وأرقامها بشكل ديناميكي.
- **تتبع الزوار والتحليلات (Visitor Analytics):** نظام داخلي لتتبع زيارات الصفحات ومصادر التصفح.
- **القائمة البريدية ونماذج التواصل (Forms & Subscriptions):** نماذج طلب عروض أسعار وتواصل ونشرات بريدية تفاعلية.

### ⚙️ 2. لوحة التحكم المتطورة (TechCMS Admin Panel)
- **إدارة المحتوى المتقدمة:** جداول ديناميكية مدعومة بمكتبة **jqGrid** تتيح البحث المتقدم، الفلترة اللحظية، الفرز، والتصدير (Excel / PDF).
- **إدارة الأقسام والصفحات:**
  - بيانات الشركة والاتصال الأساسية.
  - قطاعات الأعمال والأنشطة والشركات التابعة.
  - المنتجات، التصنيفات، والمشاريع.
  - المقالات والأخبار وتحديثات المؤسسة.
  - سلايدر الصفحة الرئيسية والبنرات الإعلانية.
  - آراء العملاء (Testimonials)، قيمنا وأهدافنا، ومميزاتنا (Why Us / Features).
  - معارض الصور والفيديو.
- **مدير الملفات المتطور (Responsive Filemanager):** رفع وإدارة الصور والملفات وتعديلها بسهولة.
- **إدارة المستخدمين والصلاحيات المتقدمة:**
  - تقسيم المستخدمين إلى مجموعات (User Groups).
  - تحديد دقيق لصلاحيات كل شاشة (عرض، إضافة، تعديل، حذف، بحث، تصدير).
- **لوحة تحليلات وإحصائيات رسومية (Dashboard & Charts):** مؤشرات أداء فورية مدعومة بمكتبة **AmCharts**.

## 🛠️ الترقيات والتوافقية مع PHP 8 | PHP 8 Modernization

تم إجراء فحص وتطوير برمجي شامل لضمان التوافقية الكاملة والعمل بدون أية أخطاء أو تحذيرات على بيئات **PHP 8.0 حتى PHP 8.5+**:
- **تحديث محرك ADODB:** دعم دوال التأسيس الحديثة `__construct` وتمرير معرّف النتائج `_queryID` لضمان استرجاع وعرض السجلات بشكل سليم.
- **إصلاح عمليات jqGrid (AJAX CRUD):** تصحيح قراءة معرّفات الجداول وإرجاع ردود JSON المتوافقة وتأمين الجافاسكريبت بحماية `try...catch`.
- **توافق التعابير النمطية (Regex):** تصحيح صيغ دوال `preg_replace` القديمة لتتوافق مع محرك PCRE2 في PHP 8.
- **ترقية مدير الملفات (Filemanager):** ضبط دوال `mb_http_input` للعمل بسلاسة في PHP 8+.
- **تحسين استعلامات قاعدة البيانات:** إنشاء اتصال أحادي (Singleton Pattern) بقاعدة بيانات Clever Cloud MySQL 8.0 لتفادي استهلاك موارد الاتصال.

## 💻 التشغيل السريع | Quick Start

### المتطلبات الأساسية (Prerequisites):
- **PHP:** الإصدار 8.0 أو أحدث (مع تفعيل امتدادات: `mysqli`, `mbstring`, `curl`, `gd`).
- **MySQL / MariaDB:** الإصدار 8.0 أو ما يكافئه.
- **خادم ويب:** Apache / Nginx أو خادم PHP المدمج للتطوير المحلي.

### خطوات التشغيل المحلي (Local Development):
1. **استنساخ المستودع (Clone the repository):**
   ```bash
   git clone https://github.com/aeeayemen/AlslamTradingSite.git
   cd AlslamTradingSite
   ```

2. **ضبط إعدادات قاعدة البيانات (Database Configuration):**
   تأكد من مطابقة بيانات الاتصال في ملف `techcms/App/App_constant.php`:
   ```php
   define("PHPGRID_DBHOST", "YOUR_DB_HOST");
   define("PHPGRID_DBUSER", "YOUR_DB_USER");
   define("PHPGRID_DBPASS", "YOUR_DB_PASSWORD");
   define("PHPGRID_DBNAME", "YOUR_DB_NAME");
   ```

3. **تشغيل الخادم المحلي (Run Built-in Server):**
   ```bash
   php -S 127.0.0.1:8000
   ```

4. **الوصول إلى النظام (Access URLs):**
   - **الواجهة الأمامية للموقع:** [http://127.0.0.1:8000/index.php](http://127.0.0.1:8000/index.php)
   - **تسجيل الدخول للوحة التحكم:** [http://127.0.0.1:8000/techcms/Logins.php](http://127.0.0.1:8000/techcms/Logins.php)
   - **الرئيسية للوحة التحكم:** [http://127.0.0.1:8000/techcms/admin/index.php](http://127.0.0.1:8000/techcms/admin/index.php)
